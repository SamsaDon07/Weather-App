# 🌤️ God-Level Weather Web App

A modern, responsive weather web app with **multi-city search, interactive charts, and dynamic weather animations**. Built to impress, this app is perfect for portfolios and live demos.

---

## **Demo**

You can see a live demo by opening `index.html` in your browser.  

*(For full functionality, make sure to replace the API key in `script.js` with your OpenWeather API key.)*

---

## **Features**

- Search for **multiple cities** at once (comma-separated)  
- **Current weather** with temperature, humidity, wind speed, and weather description  
- **Hourly & 5-day forecast** charts powered by Chart.js  
- **Mini forecast icons** below each city card for quick glance  
- **Unit toggle** between Celsius (°C) and Fahrenheit (°F)  
- **Geolocation support** to fetch weather for your current location  
- **Dynamic background gradients** based on weather (clear, clouds, rain, snow, thunder)  
- **Animated weather effects**: clouds drifting, raindrops, snowflakes, and sun glow  
- **Glassmorphism UI** with TailwindCSS and smooth hover/transition effects  
- **Responsive design** for desktop and mobile  
- **Skeleton loader** while fetching data
